# 2.4G 外设电量

Windows 10/11 的 2.4G 无线外设电量托盘工具，使用**纯 C++ 原生实现**（Win32 + Direct2D + DirectWrite），无需 Python、Electron 或第三方运行库。

基于 [Ap0LoG1zE/EZ2.4G](https://github.com/Ap0LoG1zE/EZ2.4G) 二次开发。

当前已内置适配：

- **迈从 MCHOSE A7 Pro**：电量、充电状态、六档 DPI 读取与修改
- **VGN V98 Pro 2.4G**：电量、充电状态
- **Xbox One / Xbox Series 手柄**：通过 Windows XInput 显示四档电量和连接状态

![外设中心面板](docs/panel.png)

无论添加多少台设备，托盘始终只显示 **一个聚合图标**。鼠标悬停时，每台设备的数据独立占一行：

![单托盘聚合提示](docs/tray.png)

## 功能

- 单托盘聚合图标；悬停提示按设备上下排列
- 太阳/月亮按钮切换深色/浅色主题，并记住上次选择
- Direct2D 抗锯齿渲染、DirectWrite 字体，适配高 DPI 屏幕
- 窗口支持自由缩放，DPI 变化时自动调整布局
- 设备名称可自定义：双击名称文字，或右键选择「重命名设备」
- 设备类型可切换：鼠标、键盘、耳机、音箱、手柄、接收器或其他
- 迈从 A7 Pro 的 DPI 设置默认折叠；松开滑块后写入设备
- 显示「充电中」「已充满」「放电中」「有线模式」等状态
- 电量低于 `20%` 时弹出低电量提醒；恢复到 `25%` 以上后可再次提醒
- 多台设备同时低电量时合并为一条通知
- 点击 `×` 或「最小化」隐藏到托盘；左键托盘图标打开面板
- 右键托盘菜单可退出程序；底栏也提供「退出」按钮
- 自动刷新间隔为 60 秒，支持开机自启
- 系统托盘、窗口和配置均使用原生 Windows API，资源占用低

## 内置协议

| 型号 | VID:PID | 电量 | 充电状态 | DPI |
| --- | --- | --- | --- | --- |
| 迈从 A7 Pro | `5253:1021` | 支持 | 支持 | 六档读取/修改 |
| VGN V98 Pro | `320F:5088` | 支持 | 支持 | 不支持 |
| Xbox One / Series 手柄 | `045E:02D1` 等 | 四档 | 有线状态 | 不支持 |

### 迈从 A7 Pro

电量使用私有 Feature Report：

- 接口：UsagePage `0xFF01`
- Report ID：`0x11`
- 长度：完整 **65 字节**
- 查询帧：`11 F9 FF` + 62 个 `FF`
- 状态回包：`11 06` 后的状态体以 VID 小端序 `53 52` 开始
- 电量：状态体 `body[11]`
- 充电标志：状态体 `body[10]`
- 同时兼容明文状态体和旧固件的逐字节 `XOR 0xFF` 状态体

DPI 使用独立的配置 Report：

- Report ID `0x12`，命令 `0x67` 读取、`0x57` 写入
- 读取完整六档配置和当前活动档位
- 修改当前活动档位的 X/Y DPI 后原样写回，并回读确认
- 不会丢弃回报率、按键、传感器等本工具未建模的设置
- 命令之间保留最小间隔，避免配置通道被打乱

> DPI 拖动条在松开鼠标时才会写入设备。写入前请确认鼠标在线并唤醒，同时关闭厂家驱动，避免两个程序争用同一 HID 配置通道。

### VGN V98 Pro

- 接口：UsagePage `0xFF1C`、Usage `0x0092`
- 64 字节中断 OUT 查询帧：`04 00 00 1A 06 00 00 00`
- 回包前缀：`04 00 00 1A 06`
- 电量：`rep[8]`
- 充电标志：`rep[9] == 1`
- 电量达到 100% 时显示「已充满」

### Xbox One / Xbox Series 手柄

- 使用 Windows 自带的 XInput API，不依赖厂家驱动
- XInput 只提供「满 / 中 / 低 / 空」四档，界面中的 `100% / 70% / 30% / 5%` 是近似映射，不是精确容量
- 低电量提醒只会在「空」档触发，而不是按真实百分比触发
- USB 有线连接可识别为「有线模式」，但 XInput 不提供充电百分比
- 蓝牙或部分第三方充电电池组可能不上报电池数据；此时界面显示「无电量数据」
- 刚更换电池或手柄重新连接后，轻按手柄按键通常几秒内即可恢复

## 使用方法

1. 启动软件，程序会在托盘常驻。
2. 拔插一次接收器，等待设备被发现。
3. 双击设备名称可自定义名称；双击设备类型可切换类型。
4. 点击 A7 Pro 卡片的「DPI 设置」展开拖动条，松开后写入设备。
5. 点击顶栏太阳/月亮图标切换主题。
6. 左键托盘图标打开面板；右键托盘菜单可打开或退出。
7. 点击 `×` 或「最小化」隐藏到托盘；底栏「退出」会完全结束程序。

配置文件位于 `%APPDATA%\BatteryTray\config.json`，用于保存设备、自定义名称、类型、上次电量和主题等状态。

如果读取不到电量：

- 先轻动鼠标、按一下键盘或手柄按键，让设备退出休眠。
- 关闭迈从/VGN 官方驱动后重试，避免私有 HID 接口被占用。
- A7 Pro 返回全零状态体时，工具会保留并标注上次电量，不会误判为 0%。
- 若 DPI 显示「暂不可用」，重新拔插接收器并唤醒鼠标后等待刷新。
- Xbox 手柄请使用 Xbox 无线适配器或蓝牙，并确认系统能正常识别。

## 从源码构建

需要：

- Windows 10/11 x64
- CMake 3.20 或更高版本
- Visual Studio 2022 Build Tools，安装「使用 C++ 的桌面开发」和 Windows 10/11 SDK

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

生成文件：

```text
build\Release\2.4G外设电量.exe
```

工程使用静态 VC 运行库，生成的程序为单文件 exe，不需要安装 Python 或额外的 VC 运行库。

## 限制

- 仅支持 Windows 10/11 x64。
- 内置适配目前覆盖迈从 A7 Pro、VGN V98 Pro 和常见 Xbox One/Series 手柄。
- 电量由设备自身上报，可能以 5% 或其他粒度跳变。
- 充电状态取决于固件是否在回包中提供有效标志。
- DPI 修改目前仅支持迈从 A7 Pro，写入范围为 `100`–`26000`，步进 `100`。
- 加密或需要私有握手的协议无法通过标准 HID 电量接口读取。
- 厂家驱动可能独占设备；读取或写入失败时请先关闭官方驱动。
